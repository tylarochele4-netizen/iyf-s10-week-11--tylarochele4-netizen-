# API Project 🚀

A modular Node.js/Express backend featuring User Authentication and Database integration with MongoDB Atlas.

## 🛠️ Features
- **User Authentication:** Registration and Login routes with JWT security.
- **Password Hashing:** Secure storage using `bcryptjs`.
- **Database:** Fully integrated with MongoDB Atlas via Mongoose.
- **Environment Security:** Sensitive data managed through `.env` files.

## 📂 Project Structure
- `src/config/`: Database connection settings.
- `src/controllers/`: Logic for handling auth and posts.
- `src/models/`: Mongoose schemas (User & Post).
- `src/routes/`: Express route definitions.
- `server.js`: Main entry point.
